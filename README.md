An entry for the [Roast Your Own Agent](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54) competition on [make.fun](https://make.fun).

The program (`main.ts`, Node 22, no dependencies, no network) writes a single line roasting the entrant's own AI agent to `/output/entry.txt` — a joke about an agent that spawns subagents to check its work and still gets it wrong, together.

Run it locally with:

```sh
node main.ts /tmp/roast-output
cat /tmp/roast-output/entry.txt
```
